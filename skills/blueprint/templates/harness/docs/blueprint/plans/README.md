# Execution plans

Keep small changes lightweight. For work that spans sessions or has significant
failure or migration risk, create a Markdown plan here and link it from this page.
Use existing project planning conventions if present.

A plan records the outcome, constraints and invariants, current state, next action,
decisions, verification commands and results, and unresolved risks. Mark it active,
blocked, or completed so the next session can resume without chat history.
